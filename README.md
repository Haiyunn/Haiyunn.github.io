# Haiyun Wei academic homepage

This is a small static site prepared for GitHub Pages.

## Publish after confirming the domain

1. Confirm the desired public address. For the GitHub account `Haiyunn`, the standard GitHub Pages address would be `https://haiyunn.github.io/`; a custom domain needs to be supplied and configured separately.
2. Create a **public** repository named to match the confirmed address (for the standard address, `Haiyunn.github.io`).
3. Upload `index.html` and `style.css` to the repository root and commit them to the `main` branch.
4. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub Pages publishes the site after its first build. For a custom domain, configure it in Pages and add the DNS records GitHub specifies.

Before publishing, check the publication list, especially paper status and author order, and add a portrait or paper/project images if you want them displayed. The current portrait is an initials-based illustration.
